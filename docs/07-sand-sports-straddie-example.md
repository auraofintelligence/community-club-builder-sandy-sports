# Sandy Sports Worked Example

This is the example thread. It is not a claim that any site, partner, approval or funding is secured.

## Club First, Site Later

The source drafts explore sand sports around Amity, Dunwich / Ballow Road, Point Lookout, outdoor cinema, media systems and a distributed island model.

This repo turns that into a club-building sequence:

1. Form the founding group.
2. Incorporate properly.
3. Set the leadership culture.
4. Build the admin system.
5. Run small test activities.
6. Gather evidence.
7. Seek partnerships and permissions.
8. Grow only when load is shared.

## Possible Program Mix

Start with low-load activities:

- social beach volleyball
- beach cricket
- roundnet
- ultimate frisbee
- family sand games
- women's come-and-try sessions
- youth skills clinics
- outdoor film nights after proper permissions
- wellbeing walks and gentle movement sessions

## What Success Looks Like In The First Year

Not a big arena. Not a giant festival.

First-year success is:

- incorporated club with clean records
- balanced committee
- no lone-founder dependency
- at least 2 women in real decision-making roles
- blue card and child safety process ready if juniors are involved
- 3 small activities run safely
- volunteer system working
- member register clean
- basic money controls working
- evidence log ready for grants
- community feedback loop active

That is boring in the best way. It means the club can last.
