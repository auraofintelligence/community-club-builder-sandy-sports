# First 90 Days

This is the smallest sane pathway.

## Days 1-14: Gather The Founding Circle

- Invite 10-15 possible founders to one conversation.
- Explain the no lone hero rule.
- Ask motivation and fit questions without turning them into a purity test.
- Identify at least 7 likely members.
- Confirm whether there are enough women and family/community voices in the room.
- Create a shared folder.
- Create a shared email.
- Draft purpose and objects.

Output: a founding circle that feels real, not just names.

## Days 15-30: Prepare The Formal Start

- Choose a placeholder name.
- Check name availability.
- Read the model rules.
- Draft objects.
- Prepare founding meeting agenda.
- Prepare conflict of interest declarations.
- Prepare role cards.
- Prepare a first 6-month activity limit.

Output: ready to hold the founding meeting.

## Days 31-45: Founding Meeting

- Pass the incorporation resolution if ready.
- Adopt rules.
- Elect committee.
- Appoint application person.
- Record minutes.
- Record conflicts.
- Confirm admin stack owner and backup.

Output: clean minutes and incorporation application pack.

## Days 46-60: Set Up The Admin Spine

- Lodge incorporation application.
- Draft basic policies.
- Set up member register.
- Set up volunteer register.
- Set up asset register.
- Set up risk register.
- Set up grant evidence log.
- Prepare blue card process if children will participate.

Output: the club can hold records without chaos.

## Days 61-75: Plan One Tiny Activation

- Choose one low-risk activity.
- Confirm site permission.
- Confirm insurance.
- Confirm safety plan.
- Confirm roles.
- Confirm media consent process.
- Confirm wet weather cancellation plan.

Output: one event that can be run without heroics.

## Days 76-90: Run, Debrief, Report Back

- Run the activity.
- Count attendance.
- Log volunteer hours.
- Record issues.
- Thank helpers.
- Publish a short community update.
- Decide what to repeat, stop or improve.

Output: trust evidence.

## The 90-day Rule

If the first 90 days need one person to push everything alone, do not scale. Fix the structure first.
