# Orientation

This repo treats a club as a living community system, not just a committee, bank account and logo.

Plain version: a good club is a safe container where people can meet, move, help, learn and belong. The paperwork matters because it keeps the container clean.

## The Club We Are Trying To Build

The worked example is a sand sports club on Minjerribah / North Stradbroke Island. It could support beach volleyball, beach cricket, beach touch, roundnet, ultimate, family games, film nights, youth clinics and wellbeing gatherings.

The deeper purpose is not sport for its own sake. It is a true meeting and mixing place for wellbeing.

## The Pattern

The club should be:

- lawful before it is loud
- community-led before it is sponsor-led
- mixed gender or female-led before old habits settle in
- culturally respectful before it talks about Country
- digitally organised before admin piles up
- small enough to test before it asks for big money

## The Point Lookout Fishing Club Lesson

The lesson carried into this repo is blunt: if people join for the wrong reasons, or if everything falls onto one person, the club will not hold.

So the design starts with load-sharing.

Every important job needs:

- one named lead
- one backup
- one checklist
- one shared folder
- one next review date

That sounds boring. It is actually freedom. It means the founder can sleep.
