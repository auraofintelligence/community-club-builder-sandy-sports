# Agent Notes

Use Australian English.

This repo is a public-facing community club playbook. Keep the tone practical, welcoming and source-honest. Do not make private promises, do not imply site approval, and do not expose local source paths.

Keep the repo separate from Amity and Ballow Road projects. Reference them as adjacent context only.

The central design rule is simple: a club should not depend on one exhausted founder. Prefer shared roles, visible records, short checklists, backup people, and AI-assisted admin that humans review.

When adding legal, grant, child-safety, tax or governance claims, check current official sources first and add the link to `docs/09-source-map.md` and `data/source-register.json`.

When writing templates, explain the step like the reader is smart but new to code and formal club admin. No long lectures. Small steps. Clear next action.
